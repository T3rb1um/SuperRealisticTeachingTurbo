# Klasse im Griff!

Ein kleines, gemütliches Browserspiel: Du bist Lehrkraft an einer Berufsschule und hältst deine Azubis bei der Arbeit.

**Spielen:** https://t3rb1um.github.io/SuperRealisticTeachingTurbo/

- PC: WASD/Pfeile laufen, E interagieren, Q Arbeitsform, F Vollbild
- Handy (quer): links ziehen zum Laufen, rechts E und Q. Tipp: „Zum Startbildschirm hinzufügen“ für echtes Vollbild.

Dieses Repo enthält nur die veröffentlichten Spieldateien.
